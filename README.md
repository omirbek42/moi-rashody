# Мои расходы

Личное веб-приложение для учёта бытовых расходов: бюджет на месяц, категории, карты, график по дням и импорт банковских выписок (.xlsx, .xls, .csv). Требования — в [PRD.md](PRD.md).

Всё приложение — один файл `index.html`. На GitHub Pages данные хранятся в браузере (localStorage), в версии на claude.ai — в облаке.
