# PRD: «Мои расходы»

**Версия документа:** 1.1
**Дата:** 3 октября 2026
**Статус:** MVP работает, версия 1.1 в разработке

---

## 1. Обзор

«Мои расходы» — личное веб-приложение для ежедневного учёта бытовых расходов. Оно открывается по ссылке на телефоне и на компьютере, хранит записи в облаке и видно только владельцу.

## 2. Проблема

Бытовые траты разбросаны по нескольким банковским картам и наличным. В итоге непонятно:
- сколько уходит за месяц и на что именно;
- укладываюсь ли я в бюджет;
- с какой карты сколько потрачено.

Банковские приложения показывают траты только по своему банку, а наличные не видны нигде.

## 3. Цели

| Цель | Как измеряем |
|---|---|
| Видеть все расходы за месяц в одном месте | Траты по картам и наличными попадают в приложение |
| Контролировать бюджет | Видно остаток бюджета и сколько можно тратить в день |
| Тратить на учёт минимум времени | Ручная запись занимает до 10 секунд, импорт выписки — до 2 минут |

## 4. Пользователь

Один человек, владелец приложения. Ведёт личный и семейный бюджет, платит несколькими картами и наличными. Чаще всего пользуется приложением с телефона.

## 5. Ключевое ограничение: прямая привязка карт

Автоматическая синхронизация с банковскими картами **не делается**:
- банки дают доступ к операциям только лицензированным финансовым сервисам через официальные интерфейсы (Open Banking);
- приложение не может само получать данные из внешних систем;
- хранить полные номера карт, сроки действия и CVV небезопасно и запрещено правилами безопасности платёжных систем.

**Решение:** полуавтоматический учёт. Траты по картам загружаются из банковской выписки (Excel/CSV), наличные вписываются вручную. Карта в приложении обозначается только названием и последними четырьмя цифрами.

**Альтернатива** (вне рамок проекта): сторонние приложения с поддержкой банков (например, «Дзен-мани», CoinKeeper), если они работают с банками пользователя.

## 6. Объём работ

### 6.1. MVP (готово)
- Ручная запись расхода: сумма, категория, дата, комментарий.
- 8 категорий: Продукты, Транспорт, Дом и ЖКХ, Кафе, Здоровье, Связь и интернет, Одежда, Другое.
- Итоги месяца: всего, за сегодня, в среднем в день, число записей.
- Разбивка по категориям с долями в процентах.
- График трат по дням месяца.
- Список записей по дням, удаление с подтверждением.
- Переключение между месяцами.
- Бюджет на месяц: остаток, перерасход, сколько можно тратить в день.
- Выбор валюты: ₸, ₽, $, €, сом.
- Хранение в облаке, доступ только у владельца.
- Адаптивность под телефон, светлая и тёмная тема.

### 6.2. Версия 1.1 (текущий релиз)
1. **Мои карты.** Список способов оплаты: название и последние 4 цифры (необязательно). По умолчанию есть «Наличные». Приложение не даёт сохранить полный номер карты.
2. **«Чем оплачено» у каждой траты.** Выбор карты или наличных при ручной записи.
3. **Отчёт по картам.** Сколько потрачено за месяц с каждой карты.
4. **Импорт выписки:**
   - форматы: .xlsx, .xls, .csv;
   - пользователь указывает, в каких столбцах дата, сумма и описание (приложение пытается угадать само);
   - выбор карты, к которой относится выписка;
   - распознаются форматы дат `дд.мм.гггг`, `дд.мм.гг`, `гггг-мм-дд` и даты Excel;
   - суммы с пробелами, запятой и знаком валюты;
   - если в выписке есть суммы с минусом, импортируются только они (расходы), иначе все строки;
   - категория подбирается автоматически по ключевым словам в описании;
   - перед импортом показывается предпросмотр: сколько строк и на какую сумму;
   - повторно загруженные операции не дублируются (проверка по дате, сумме и описанию).
5. **Категория «Ремонт».** Для расходов на ремонт квартиры.

### 6.3. Следующие версии (бэклог)
- Свои категории: добавить, переименовать, выбрать цвет.
- Шаблоны импорта под конкретные банки (по присланным образцам выписок).
- Импорт PDF-выписок.
- Учёт доходов и остатка.
- Отчёт за год и сравнение месяцев.
- Регулярные платежи (ЖКХ, связь) с напоминанием.

- Отдельный бюджет проекта «Ремонт».

## 7. Функциональные требования

| № | Требование | Приоритет |
|---|---|---|
| F1 | Добавить расход с суммой больше 0, категорией, датой (по умолчанию сегодня), комментарием до 80 символов, способом оплаты | Must |
| F2 | Удалить запись с подтверждением в два нажатия | Must |
| F3 | Показать итоги выбранного месяца | Must |
| F4 | Разбивка по категориям и по картам | Must |
| F5 | График по дням, сегодняшний день выделен | Should |
| F6 | Бюджет на месяц, остаток и дневной лимит | Should |
| F7 | Управление списком карт: название + последние 4 цифры | Must |
| F8 | Импорт выписки с сопоставлением столбцов, автокатегориями, предпросмотром и защитой от дублей | Must |
| F9 | Пометка и удаление примеров записей | Should |

## 8. Модель данных

**`expenses/{id}`** — одна трата:
| Поле | Тип | Описание |
|---|---|---|
| amount | число | Сумма, больше 0 |
| category | строка | Код категории |
| note | строка | Комментарий или описание из выписки |
| date | строка | `ГГГГ-ММ-ДД` |
| payment | строка | Код способа оплаты |
| createdAt | число | Время создания |
| source | строка | `manual` или `import` |
| importKey | строка | Ключ для защиты от дублей (у импортированных) |
| example | булево | Пример записи |

**`settings/main`** — настройки:
| Поле | Тип | Описание |
|---|---|---|
| budget | число | Бюджет на месяц, 0 — не задан |
| currency | строка | Символ валюты |
| cards | массив | `[{id, name, last4}]` |

## 9. Безопасность и приватность
- Читать и изменять данные может только владелец.
- Полные номера карт, сроки действия и CVV не запрашиваются и не сохраняются. Строка, в которой 8 и больше цифр подряд, отклоняется как название карты.
- Файл выписки разбирается прямо в браузере и никуда не отправляется. Сохраняются только дата, сумма, описание и категория.

## 10. Нефункциональные требования
- Работает в мобильном браузере начиная с ширины экрана 360 px.
- Светлая и тёмная тема по настройке устройства.
- Импорт до 1000 строк за раз.
- Интерфейс на русском языке.
